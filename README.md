# Particle Resonance 001

https://saruoka.github.io/particle-resonance/

Three.js / WebGL の音楽反応パーティクル作品。低音で広がり、中音で流れ、高音で光る。曲がなくてもデモが動く。

A music-reactive particle piece. Bass opens the cloud, mids steer the flow, and highs spark the light. With no song, a demo plays.

## iPhone での使い方 / On iPhone

1. Safari で上の URL を開く。Open the URL above in Safari.
2. 画面をタップする。Tap the screen.
3. 「音楽を選択」を押し、ファイル App から曲を選ぶ。再生は端末の中だけで行われ、何もアップロードされない。Tap 「音楽を選択」 and pick a song from Files. Playback stays on the device; nothing is uploaded.
4. 曲を選ばなければ、デモのまま表示される。If you do not pick a song, the demo keeps playing.
